Relationships

From Type To Detail
Book Inheritance LibraryItem extends · overrides getAuthorOrPublisher → author
Magazine Inheritance LibraryItem extends · overrides getAuthorOrPublisher → publisher
AvailableState Implements ItemState checkout → creates borrow & transitions state
CheckedOutState Implements ItemState return → ends borrow; hold → addObserver
OnHoldState Implements ItemState checkout only by holder; removes observer after
SearchByAuthorStrategy Implements SearchStrategy filters by author/publisher field
SearchByTitleStrategy Implements SearchStrategy filters by title field
LibraryItem Observer Subject Member CopyOnWriteArrayList<Member> observers; calls update()
LibraryItem Composition BookOrMagazineCopy owns List<BookOrMagazineCopy>; copies self-register on construction
BookOrMagazineCopy Association LibraryItem back-ref to parent item (final field)
BookOrMagazineCopy Association ItemState currentState field; starts as AvailableState
Borrow Association BookOrMagazineCopy holds ref to borrowed copy
Borrow Association Member holds ref to borrowing member
Member Composition Borrow owns List<Borrow> memberBorrowRequests
TransactionService Composition Borrow HashMap<String,Borrow> keyed by copy ID
ItemFactory Dependency Book / Magazine createItem() instantiates based on ItemType switch
ItemFactory Uses ItemType switch on enum to pick concrete class
LibraryManagement Composition LibraryItem catalog HashMap owns all items
LibraryManagement Composition Member members HashMap owns all members
LibraryManagement Composition BookOrMagazineCopy copies HashMap owns all physical copies
LibraryManagement Dependency ItemFactory addItem() delegates creation to factory
LibraryManagement Dependency SearchStrategy search() accepts strategy as parameter (runtime injection)
AvailableState / OnHoldState Dependency TransactionService calls getInstance().createBorrowRequest()
CheckedOutState Dependency TransactionService calls getInstance().endBorrowRequest()
