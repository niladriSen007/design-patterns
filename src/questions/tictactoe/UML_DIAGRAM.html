🎯

Strategy Pattern

WinningStrategy interface — Row, Column, Diagonal swap without changing Game.

👁

Observer Pattern

Game notifies GameObservers on WIN/DRAW. Scorecard updates scores reactively.

🏛

Facade Pattern

TicTacToeSystem hides Game + Scorecard behind createGame/makeMove/getStatus.

🔒

Singleton Pattern

TicTacToeSystem uses double-checked locking with volatile for one instance.

⚡

Thread Safety

move() synchronized · ConcurrentHashMap in Scorecard · CopyOnWriteArrayList for observers.

📦
